# Prompt library

Every prompt follows the same structure: role and objective, inputs, context, scope,
discovery, procedure, validation, security, deliverables, completion report. Replace each
`<parameter>` before use.

| Prompt | Use for | Skill |
|---|---|---|
| [audit-repository.md](audit-repository.md) | Establish verified facts about the repo | `/repo-audit` |
| [implement-feature.md](implement-feature.md) | New behaviour with acceptance criteria | `/implement-feature` |
| [bug-fix.md](bug-fix.md) | Reproduce, root-cause, and fix a defect | `/bug-fix` |
| [refactor.md](refactor.md) | Behaviour-preserving structural change | — |
| [test-and-verify.md](test-and-verify.md) | Run and report checks for a change | `/test-and-verify` |
| [security-review.md](security-review.md) | Review a change or area for security issues | `/security-review` |
| [documentation-update.md](documentation-update.md) | Bring docs in line with code | — |
| [dependency-update.md](dependency-update.md) | Add, upgrade, or remove a dependency | — |
| [release-readiness.md](release-readiness.md) | Decide whether a revision can be released | `/release-readiness` |
| [commit-and-pr.md](commit-and-pr.md) | Commit signed work and open a draft PR | — |
