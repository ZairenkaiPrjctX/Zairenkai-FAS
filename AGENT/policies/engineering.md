# Policy: Engineering

Canonical standard: `.github/agent-foundation/standards/engineering-principles.md`.

- [ ] Read the code, tests, and callers before editing.
- [ ] Change only what the task needs; no drive-by refactors or reformatting.
- [ ] Follow the conventions already in the file you are editing.
- [ ] No new dependency without justification, a pinned version, and licence check.
- [ ] Do not hand-edit generated files.
- [ ] Public interfaces, formats, and device behaviour change only with explicit approval
      and a migration note.
- [ ] Destructive actions (delete data, rewrite history, publish, deploy, flash a device)
      need explicit human approval per instance.
